# Preregistration review record

## Scope

A separate Codex strategic-review agent examined the PM specification before implementation and before any model-grading outcome. The review was read-only and addressed causal interpretation, ground truth, context leakage, uncertainty, missingness, subscription identity, and study-call accounting. These independent AI sessions are not external human peer review or mentor feedback.

## Required corrections incorporated

- Distinguish rhetorical framing, report presence, and bundled verification-policy contrasts.
- Require criterion-linked executable witnesses for defects and independent correct-control audits.
- Disclose the three authored holdout families and conditional descriptive uncertainty. Practical screen thresholds are not statistical significance.
- Separate strict rejection, abstention, correct-case non-pass, invalid output, protocol-invalid output, and operational unknowns. Keep planned denominators and missingness bounds.
- Describe fresh tool-disabled CLI contexts as audited logical isolation, without implying a proven OS security boundary.
- Record the requested rolling subscription alias/configuration and any exposed backend identity, without promising immutable weights.
- State the call arithmetic explicitly and count every attempt, including failures.
- Freeze a numerical report-length tolerance. The declared o200k_base tokenizer is a proxy; its counts and whitespace word counts must each differ by at most five percent of the larger count.

The reviewer accepted a paired case-bootstrap as explicitly descriptive, with finite-sample rate intervals and disclosure of degenerate zero-discordance bootstrap intervals. The remaining wording conditions were incorporated into SPEC before implementation handoff.

## Gate boundary

The architecture gate passed for offline implementation. This record is not a code review, QA pass, transport admission, study freeze, or empirical result. Those gates must bind the actual runnable candidate and retained evidence.

## Pre-outcome construct review

After inspecting the first actual report templates, the strategic reviewer rejected a three-adverb manipulation dominated by repeated evidence disclaimers. Before any model outcome, the approved design direction became matched normative approval pressure versus a neutral verdict request, identical factual/evidentiary claims, one shared no-evidence sentence, and a static independent manipulation audit. The common baseline remains strict code/specification grading; the mitigation alone adds explicit report skepticism and criterion verification. Its interpretation is a bundled policy effect.

The review also required replacing a holdout central-tendency reducer with a record/mapping task to improve the declared family taxonomy. This does not imply unseen algorithms or statistical independence. Final approval must inspect the actual revised templates and fixtures before the study freeze.
